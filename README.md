# UAV Flight Log Research

Research project focused on analyzing experimental UAV flight-controller logs from RadioLink CrossFlight using Python and data science.

## Objectives

- Extract and interpret flight-controller telemetry
- Analyze GPS, IMU, vibration, attitude, and motor outputs
- Automate repetitive flight-log analysis
- Explore machine-learning methods for anomaly detection

## Technology

Python, JupyterLab, PyMAVLink, Pandas, NumPy, Matplotlib, Scikit-learn

## Status

Phase 1: Environment setup and flight-log exploration.

## Data

Experimental flight logs are kept locally and are not included in this repository.
